# Figures

All figures are generated by `../analysis/make_figures.py` from the archived raw records. No value is
synthetic. Each figure exists as a PDF (vector, for LaTeX) and a PNG.

| File | Shows | Data | Status |
|---|---|---|---|
| `fig1_exp1_knee` | Firmware ARM clock against SoC temperature (6,894 samples); 98 % line; knee 80.8 °C | Exp. 1 archive `a84997e7`, `exp1.telemetry.jsonl` | confirmatory (G1) |
| `fig2_exp2_sT` | Bin-median HOT latency against bin-median temperature, 2 ramps; preregistered OLS slope and CI | Exp. 2 run -03 archive `5bb8d13a`, `exp2.meta.json` (bins recomputed from jobs, identical) | confirmatory (G2) |
| `fig3_exp3_trajectories` | Median and IQR SoC temperature against time within a sequence, per ordering | Exp. 3 archive `4e4ae7f6`, `exp3.telemetry.jsonl` | descriptive (supports G4) |
| `fig4_exp3_time_above_knee` | Time above the knee per sequence, with medians | `exp3.meta.json` runs (recomputed values equal the record) | confirmatory (G4) |
| `fig5_exp3_outcomes` | Per-sequence P99, mean latency and throughput, with medians | `exp3.meta.json` runs | confirmatory (G5/G5b) |
| `fig6_exp3_tail_ccdf_exploratory` | Pooled latency CCDF per ordering (6,000 jobs each) | `exp3.jobs.jsonl` | **exploratory** |
| `fig7_exp3_session_order_exploratory` | Cooldown, time above the knee and P99 per sequence, against session time | `exp3.meta.json`, `exp3.telemetry.jsonl` | **exploratory** |

**Plotting notes:**
- In Figs. 1, 4 and 5, points are jittered horizontally (Fig. 1 also by ±0.15 °C in temperature) for
  visibility only. Values are not altered.
- In Fig. 3, telemetry is interpolated onto a 1 s grid to compute the medians and IQRs across sequences.
